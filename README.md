# Нейросеть для распознавания рукописных цифр

Проект на Python, который обучает свёрточную нейронную сеть (CNN) распознавать рукописные цифры (0–9) и позволяет проверить модель на собственной картинке.

---

## 📌 Что делает эта программа

Программа решает задачу **классификации изображений**: получает на вход картинку с одной рукописной цифрой и отвечает, какая это цифра (0, 1, 2, …, 9), а также показывает уверенность модели в процентах.

**Пример работы:**

```
Введите имя картинки с цифрой (или 'выход'): my_digit.png

>>> РАСПОЗНАНА ЦИФРА: 7
>>> Уверенность: 98.73%
```

---

## 🧠 Как это работает — по шагам

### 1. Обучение модели

При первом запуске программа:

1. **Скачивает датасет MNIST** — 70 000 изображений рукописных цифр (28×28 пикселей, оттенки серого). 60 000 — для обучения, 10 000 — для проверки.
2. **Создаёт свёрточную нейронную сеть (CNN)** — архитектуру, которая хорошо подходит для анализа изображений.
3. **Обучает её 5 эпох** — то есть 5 раз «прогоняет» весь обучающий набор и постепенно подстраивает веса.
4. **Сохраняет обученную модель** в файл `digit_model.keras`.

После обучения точность на тестовых данных достигает **≈ 99%** — модель ошибается примерно на 1 картинке из 100.

> ⚠️ Обучение занимает 3–10 минут и происходит **только один раз**. При следующих запусках модель сразу загружается из файла.

### 2. Распознавание картинки

Когда вы вводите имя файла, программа:

1. **Открывает изображение** и переводит его в оттенки серого.
2. **Инвертирует цвета при необходимости** — MNIST содержит белые цифры на чёрном фоне; если у вас чёрная цифра на белом, программа автоматически перевернёт изображение.
3. **Обрезает по границам цифры** — убирает лишний белый фон.
4. **Вписывает цифру в квадрат** с сохранением пропорций.
5. **Масштабирует до 28×28** с полями 4 пикселя по краям (как в MNIST).
6. **Отправляет картинку в модель**, которая возвращает вероятности для каждой цифры 0–9.
7. **Выводит цифру с наибольшей вероятностью** и уверенность в процентах.

## 🏗️ Архитектура нейросети

Модель состоит из 7 слоёв:

| Слой | Что делает | Размер выхода |
|---|---|---|
| **Вход** | Принимает картинку 28×28×1 (оттенки серого) | 28 × 28 × 1 |
| **Conv2D (32 фильтра, 3×3)** | Находит простые признаки: штрихи, дуги, углы | 28 × 28 × 32 |
| **MaxPooling 2×2** | Уменьшает размер в 2 раза, оставляя главное | 14 × 14 × 32 |
| **Conv2D (64 фильтра, 3×3)** | Находит сложные признаки: петли, пересечения | 14 × 14 × 64 |
| **MaxPooling 2×2** | Снова уменьшает размер | 7 × 7 × 64 |
| **Flatten** | Превращает 3D-карту признаков в плоский вектор | 3136 |
| **Dense (128, ReLU)** | Полносвязный слой, обучается различать признаки | 128 |
| **Dropout (0.5)** | Отключает половину нейронов при обучении — защита от переобучения | 128 |
| **Dense (10, Softmax)** | Выход: вероятности для 10 цифр (0–9) | 10 |

**Что такое свёртка (Conv2D)?**  
Это операция, при которой маленькое окно (3×3 пикселя) «скользит» по изображению и ищет повторяющиеся узоры. Первый слой находит простые штрихи, второй — их комбинации (дуги, петли). Так сеть учится «видеть» цифры.

**Что такое Dropout?**  
При обучении случайно отключается 50% нейронов. Это заставляет сеть не полагаться на один конкретный путь, а распределять знания по всем нейронам. Без этого модель могла бы «зазубрить» обучающие данные и плохо работать на новых картинках.

## 🖼️ Как подготовить картинку

Модель обучена на рукописных цифрах из MNIST. Чтобы она работала хорошо:

✅ **Правильно:**
- **Одна** цифра на картинке
- Крупно, по центру
- Чёрным по белому (или белым по чёрному — программа сама разберётся)
- Толстые штрихи (как маркером, не тонкой ручкой)
- Без рамок, подписей, посторонних деталей

❌ **Неправильно:**
- Несколько цифр на одной картинке
- Фото страницы книги или экрана
- Цветной фон, текстура, шум
- Цифра тонкой линией (1–2 пикселя)
- Цифра занимает 5% картинки, а остальное — фон

**Простой способ нарисовать:**  
Откройте Paint → холст 280×280 → кисть 10–15 px → нарисуйте одну цифру по центру → сохраните как `my_digit.png`.

## ⚙️ Основные параметры модели

Если хотите поэкспериментировать, вот что можно менять в коде:

| Параметр | Значение по умолчанию | Что влияет |
|---|---|---|
| `epochs` (в `model.fit`) | 5 | Больше эпох → выше точность, но дольше обучение |
| `batch_size` | 64 | Сколько картинок обрабатывать за раз |
| `Conv2D(32, ...)` | 32 фильтра | Больше фильтров → больше признаков, но дольше обучение |
| `Dropout(0.5)` | 0.5 | Больше → сильнее защита от переобучения |
| `optimizer="adam"` | Adam | Алгоритм обучения (можно попробовать `"sgd"`) |

**Если хотите повысить точность** — увеличьте `epochs` до 10–15. Ожидаемый результат: **99.3–99.5%**.

## ❓ Частые проблемы

| Проблема | Причина | Решение |
|---|---|---|
| `ModuleNotFoundError: tensorflow` | Библиотеки не установлены | `pip install -r requirements.txt` |
| Уверенность 10–15% | Картинка не похожа на MNIST | Нарисуйте цифру крупнее, обрежьте фон |
| Всегда одна и та же цифра | Модель не обучена | Удалите `digit_model.keras` и запустите заново |
| Долго обучается | Первый запуск | Подождите до 15 минут |
| `Файл не найден` | Картинка в другой папке | Проверьте имя и путь |

## 🔬 Как проверить, что модель обучена нормально

Запустите этот короткий тест:

```python
import tensorflow as tf
from tensorflow.keras.models import load_model

model = load_model("digit_model.keras")
(_, _), (x_test, y_test) = tf.keras.datasets.mnist.load_data()
x = x_test[:1].astype("float32")[..., None] / 255.0

p = model.predict(x, verbose=0)[0]
print("Правильный ответ:", y_test[0])
print("Модель думает:  ", p.argmax())
print("Уверенность:    ", f"{p.max()*100:.2f}%")
```

Если уверенность **95–100%** — модель в порядке. Если **10–20%** — обучение не завершилось, запустите `python digit_ai.py` заново.

## 📚 Что можно улучшить

Проект задуман как учебный. Возможные доработки:

- **Аугментация данных** — повороты, сдвиги, масштаб картинок при обучении. Модель станет устойчивее к наклонам и разному почерку.
- **Больше эпох** — 10–15 вместо 5.
- **Добавить BatchNormalization** — ускоряет обучение и стабилизирует его.
- **Веб-интерфейс** — на Flask или Streamlit, чтобы загружать картинки через браузер.
- **Обучение на своём датасете** — например, на фотографиях рукописных цифр.
